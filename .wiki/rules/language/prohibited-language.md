# Prohibited Language

> Words and phrases to avoid, with replacements. Scan every draft against this list.

## Filler & Hedging

| Prohibited | Replace with |
|---|---|
| just | (delete) |
| actually | (delete) |
| sort of / kind of | (delete) |
| it is important to note that | (delete) |
| please note that | (delete) |
| at the end of the day | (delete) |
| leverage | use |
| utilize | use |
| facilitate | enable / help |
| robust (as filler) | specific quality |
| seamless | (delete — say what actually happens) |

## Overclaiming

| Prohibited | Replace with |
|---|---|
| guaranteed / guarantee | verified by / passes |
| 100% | the exact count |
| always / never | qualified statements |
| best-in-class | specific comparison |

## Vagueness

| Prohibited | Replace with |
|---|---|
| relevant documentation | the actual path/link |
| various / several | the actual count |
| things / stuff | the actual noun |
| etc. | the actual list |

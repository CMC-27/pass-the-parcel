# Directory Naming Convention

## Rules

- kebab-case for most directories (`src/components/ui/`, `src/hooks/`)
- PascalCase only for component directories (`src/components/Button/`)
- No deep nesting (max 3-4 levels recommended)
- Feature-based grouping for business logic
- Type-based grouping for shared primitives

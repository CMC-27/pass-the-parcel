# CSS Class Naming Convention

## Rules

- Utility-first approach (TailwindCSS or similar)
- Component-scoped styles via CSS Modules or CSS-in-JS
- No global class name collisions
- BEM-like naming for custom CSS: `block__element--modifier`
- Theme tokens used instead of hardcoded color/border values

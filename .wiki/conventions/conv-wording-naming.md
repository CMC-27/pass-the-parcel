# Wording and Terminology Convention

## Rules

- UI labels: Sentence case (`Save changes`, `Delete project`)
- Buttons: Imperative verb (`Save`, `Delete`, `Create`)
- Error messages: Human-readable, actionable (`Could not save. Please try again.`)
- Empty states: Instructional (`No projects yet. Create your first project.`)
- Confirmations: Clear consequence (`Delete 3 items? This cannot be undone.`)
- Domain terms: Consistent across all surfaces (use Glossary of Terms)

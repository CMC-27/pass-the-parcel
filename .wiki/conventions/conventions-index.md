## Conventions Overview

### File Naming
- Components: `ComponentName.tsx`
- Utilities: `camelCase.ts`
- Hooks: `useHookName.ts`
- Styles: `ComponentName.module.css`

### Component Naming
- UI primitives: `ui-component-name.md` in wiki docs
- Feature components: `feat-feature-name.md` in wiki docs

# Component Naming Convention

## Rules

- Components: PascalCase (`UserProfile`, `ButtonGroup`)
- Files match component names: `UserProfile.tsx`
- Directory components: `ComponentName/index.tsx`
- Test files: `ComponentName.test.tsx`
- Higher-order components: `withFeature()` pattern
- Custom hooks: `useHookName()` pattern

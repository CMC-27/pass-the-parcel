## The missing gate

`T1-E3.24` ships the green stamp as prose in `plan-lifecycle.md` § Gate Invocation Hygiene with **no deterministic check** behind it. The honour-system links this plan newly creates:

- **Order discipline** — no pre-pass commit stages `.devops/logs/agent-changelog.md`; the closing commit is the first commit after the gate pass; `Green stamp: <sha>` is appended only after that commit exists; only allowlist bookkeeping follows. Enforced today only by prose order (`ponytail:` ceiling recorded in the canon).
- **Recording discipline** — every stamp skip records `suite skipped — bookkeeping-only delta (stamp <sha>)`, every stamp hit records `suite invoked — real-file delta: <paths>`. Nothing asserts the line exists after a run.
- **Recorded == located** — the locator (`git log --oneline -1 -- .devops/logs/agent-changelog.md`) must return the recorded sha at push time. Verified once at the first live wrap-up (AC2), never re-asserted.

## 1 Phase 1: Expansion & Scoping
**Skill Executed:** `ptp-context-hunter` (`SINGLE`: orchestrator inline)

**Intent:**
Close the two gaps deliberately deferred from T2-E2.01. **G3 — OKF ingest:** `wiki_okf.py` is export-only; a satellite cannot import an OpenWiki/OKF bundle into `.wiki/`. **G5 — CI refresh:** CI *fails* on stale claims but never *refreshes*; drift is reported but never surfaced to a human automatically. Target end-state: a satellite can ingest a generated OKF bundle, and a scheduled drift job raises a secret-free drift issue without a human noticing first.

**In Scope:**
- **G3:** `scripts/wiki_okf.py import` — reads an `openwiki/` OKF v0.2 bundle, translates frontmatter to the local `format-version: 1` schema as `status: in-progress` drafts, registers docs in the area spoke index, emits lint-clean output.
- **G5:** `.github/workflows/wiki-refresh.yml` — scheduled (`workflow_dispatch` + weekly cron) secret-free drift job that runs `wiki_claims.py check` and raises/updates/closes a `wiki-drift` issue.
- Machinery: `sync-manifest.yaml` `machinery-version` 28→29 + `version-history.md` row + `CHANGELOG.md` line; `@wiki-update`/`@wiki-generate` skill updates; `HOW-TO.md` §6 + `SATELLITE-BOOTSTRAP.md` §5 docs.

**Out of Scope:**
- Per-symbol hashing (whole-file `ponytail:` ceiling stays — see `.wiki/rules/claims.md`).
- Model-key docs PR (see Q3 — the repo's no-secret principle wins).
- Multi-provider model matrix / personal-wiki connectors (delegate to OpenWiki).
- Renewed grounding of core slots beyond T2-E2.01.
- G8-G12 release-polish items.

**Perimeter Notes:**
- **Trust boundary:** resolved at Phase 3 — the drift job is secret-free; the docs-PR path is deferred.
- Scripts are portable surface → `machinery-version` bump + `version-history.md` row required (CI version-discipline gate).
- Ingest must not break the secret-free, no-`src/` template path (missing bundle → clean exit, never a traceback).
- Ingest output must pass `wiki_lint.py` (frontmatter, index cataloguing).
- OKF v0.2 is external: pin the version and record provenance (`okf_version`).

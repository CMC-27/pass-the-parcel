# Archived Implementation Plans

This directory contains completed and closed implementation plans. Plans are moved here from `.devops/plans/` when the task is complete via the `@agent-wrap-up` skill.

---

## Structure

- Each archived plan retains its original filename: `<slug>-plan.md`
- Plans are grouped by completion date (most recent first in the directory listing)

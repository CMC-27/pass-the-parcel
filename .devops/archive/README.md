# Archived Implementation Plans

This directory contains completed and closed implementation plans. Plans are moved here from `.devops/plans/` when the task is complete via the `@agent-wrap-up` skill.

---

## Structure

- Each archived plan retains its original filename: `<slug>-plan.md`
- Plans are grouped by completion date (most recent first in the directory listing)
- Two non-plan records live here: `planless-session-stamps.md` — the operator-ruled green stamp for plan-less sessions that land changelog commits (see its own header for why it exists) — and `agent-changelog-history.md`, the pre-index narrative record (2026-09-09 → 2026-09-25) moved verbatim out of `.devops/logs/agent-changelog.md` when the live log returned under its 500-line guideline

### Implementation Instructions (no code snippets except exact string literals: regex, SQL migration, CLI command, config key, error message)

**F8 — `scripts/sync-architecture.ps1`, `Update-TargetModelBindings` step 3:**

- Add `Find-MatchingBrace(Text, Open)` → index of the `}` matching the `{` at `Open`; string-aware (ignores braces inside JSON string literals) and escape-aware (`\` guards the next char); `-1` when unbalanced. Used for both seed slicing and target insertion.
- Add `Get-SeedAgentEntry(TgtRoot, Key)` → reads the **target's** `.devops/templates/opencode.template.json`, locates `"<key>"\s*:\s*\{`, slices the `{...}` object **verbatim**, and returns it plus the entry line's leading whitespace as its base indent. Returns `$null` when the seed, the key, or a balanced object is absent. Deliberately never `ConvertTo-Json` — that re-escapes non-ASCII descriptions and would corrupt the seeded text.
- Add `Add-TargetAgentEntry(Raw, Key, Seed)` → locates `"agent"\s*:\s*\{`, finds its matching `}` via `Find-MatchingBrace`, re-indents the seed object from the seed base indent to the target's entry indent (the `"agent"` line indent + two spaces), and inserts `,` + newline + `<indent>"<key>": <object>` **before the newline preceding the agent object's closing brace** — mirroring step 1's "anchor after the last existing row". The inserted entry carries **no** trailing comma (it is last). Returns `Ok=$false` when the agent object cannot be located (e.g. `"agent": {}`).
- Step 3 loop: build a `$present` set from the parsed target `agent` properties once; in registry-key sort order, for each absent key call `Get-SeedAgentEntry` → `Add-TargetAgentEntry`, count successes, and keep going (do **not** stamp models until every insert has landed, so offsets stay valid). On a null seed or `Ok=$false`, print the existing literal `BINDING-SKIP` plus a distinguishing suffix and `continue`. Then run the **existing** per-key model-locator stamp unchanged over the updated text.
- Write back only when a counter changed something, using the existing `UTF8Encoding($false)` idiom. Report the insertion count.
- Exact new literals: `BINDINGS: inserted {0} missing agent entry/entries: {1}`; `BINDING-SKIP` suffix `(no agent entry in target opencode.json and no seed entry to insert)`; `BINDING-SKIP` suffix `(could not locate the target opencode.json 'agent' object to insert into)`; the seed path `.devops/templates/opencode.template.json`.
- `ponytail:` mark the residual ceiling: a target whose `agent` object cannot be located (empty object, hand-minified JSON) is **not** repaired — it still reports `BINDING-SKIP` and the validator fails loud. Upgrade path: brace-match-driven object normalisation, needed only if a satellite ever ships a hand-minified `opencode.json`.

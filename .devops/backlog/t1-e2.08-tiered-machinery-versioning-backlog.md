## Operator rulings locked at intake (2026-09-24)

1. **3-level scheme, deterministic**: `major.minor.patch`; **first value `1.0.73`** — major 1 aligns with the existing `v1.0.0` tag era, patch 73 continues the count for human continuity.
2. **Bump rule is mechanical, from the diff**: patch = routine improvement (default); minor = a new capability surface (a path with no prior registry/manifest row); major = operator-contract change — the diff intersects the **reserved-surfaces set** that already exists in `plan-lifecycle.md` § Claim Protocol.
3. **Ceremony attaches to the level**: patch = one-line history row, no CHANGELOG entry, no tag; major = full row + CHANGELOG + tag. Old patch rows may later be compacted (the CI asserts only the *current* value is recorded) — this unblocks the deferred W3 length cap.
4. **Collapse the dual numbering**: the manifest value *is* the release-log Version column; one number, one writer, one check.
5. **Majors are mandatory satellite pull milestones** (the downhill half of the feedback loop).
6. **Migration in two releases**: release A ships a dotted-tolerant parser while the value is still an integer; release B flips the value. No satellite re-bootstrap; no misread window (an old `(\d+)` + `[int]` parser would truncate `1.0.73` to `1` silently).

# Parcel Plan: T2-E1.03 — Coverage Gate: Symbol-Level Evidence

> **Type:** Deferred carry-over from T2-E1.01 (Gate A, Q6). `Backlog` state — not started.
> **Created by:** `@agent-wrap-up`, 2026-09-11.

## Intent

`scripts/wiki_coverage_check.py` covers a source file when its **filename substring** (or parent folder path) appears anywhere in the domain index (`re.search(r"(?<![\w])" + re.escape(name), index_text)`). That is a weak anchor: an index row that merely mentions the string satisfies it, and a renamed symbol inside an unchanged file is invisible.

Upgrade coverage to **symbol-level evidence**: a source file is covered only when the index cites the real symbol or an explicit claim/`source` binding, so the wiki cannot silently drift when code changes shape but not name.

## In Scope (draft — re-scope at Phase 3)

- Replace the substring rule with a symbol/evidence anchor in `scripts/wiki_coverage_check.py`.
- Decide whether coverage consumes the Grounded Claims layer (`scripts/wiki_claims.py`) instead of index text.
- Keep the graceful no-op when `src/` is absent (template behaviour must not regress).

## Out of Scope

- Any change to the claims layer itself (shipped in T2-E1.01).
- Replacing `wiki_lint.py` — extend, do not fork.

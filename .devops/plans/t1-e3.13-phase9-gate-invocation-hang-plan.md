## What the fix does

1. **F1 - one canonical one-shot invocation.** `@test-and-deploy` names a **non-interactive** invocation and how to derive it (`npm test -- --run` / `npx vitest run` / `CI=true npm test`). A `watch`-shaped script is the failure, not the operator's mistake.
2. **F2 - Phase 9 gate discipline, cited not restated.** `ptp-parcel-fast` and the `template-plan.md` Phase 9 scaffold gain one line: gate commands are **one-shot**, and a gate expected to exceed the executing tool's default timeout must be invoked with an **explicit extended timeout** (or backgrounded and the result read). One home, cited — never restated per skill (Managed Simplicity / `surface-budget.md`).
3. **F3 - a named resume state.** Define the interrupted-run outcome (e.g. `HALT <code>: interrupted mid-Step-10 - resume`) with the host's duty: detect body-`PHASE_9` + `claim_status: CLAIMED` + empty evidence, then continue **Step 10 only** — never re-run Phases 1-8, never fabricate evidence.

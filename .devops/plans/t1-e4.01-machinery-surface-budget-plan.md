# Parcel Plan: T1-E4.01 - Machinery Surface Budget & Managed Simplicity

> **Origin:** User observation — *"our infrastructure and machinery is getting very complex."* Measured, not asserted: a single canon rule is independently authored in ~4–5 surfaces, so every rule change costs ~5 synchronized edits; `machinery-version` went 26 → 52 in ~5 days; and the encoding gate scans every file with an interpreted per-byte loop (13.8 s here at 228 files, >3 min at a satellite's 701). This parcel adds the missing counterweight — a **surface budget** — adopts the **Managed Simplicity** premise as the template's first principle, and trims the accumulated bloat.
>
> **Two recorded deviations** (see `.opencode/plans/run-machinery-surface-budget/decision_log.md`): (1) instantiated **directly as a claimed plan** rather than from a sprint queue, by explicit operator choice; (2) **trunk-sequential** — no `git worktree`, mirroring `@sprint-run` deviation 3, because there is exactly one claim and no concurrency to isolate.

## ⚙️ Plan Settings (FROZEN — set at plan start, read before any phase)

| Setting | Value | Meaning |
|---|---|---|
| **Mode** | `AUTO` | Orchestrator auto-clears Gates A-C **only on positive, presence-based evidence** (`.devops/rules/plan-lifecycle.md` § AUTO Gate Evidence Contract) — Gate D always halts. |
| **Agents** | `MULTI` | Comprehensive plan — full `ptp-*` delegation, independent context-isolated Group C reviewers, 4 gates. |

> **Frozen config — read before executing ANY phase.** These two settings govern the entire pipeline and are never edited after plan start. Mutable runtime state (Status / Active Persona / gates) lives ONLY in the cache-anchored `## 📍 State & Gates` section at the bottom.
>
> **Selection provenance:** both axes were chosen by the operator at plan start (`parcel` orchestrator preset = `ask`). Complexity triage fires **high on every signal** — cross-cutting (~40 files), contract change (rules + prefix + AGENTS), self-referential (edits the pipeline that executes it), irreversible (deletions). `multi_worthy` by the `touches > 3` bound.

> **Seed context:** `.opencode/plans/run-machinery-surface-budget/seed-context.md` carries the full pre-plan analysis (fan-out measurements, bloat audit, decision record). Every phase group reads it first.

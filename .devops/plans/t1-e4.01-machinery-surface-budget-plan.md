2. A retired skill folder that is *also* added to `excluded_skills` — forbidden: exclusion only narrows the derived set for fresh syncs and produces **no verdict at all**, leaving a silent orphan.
3. `-All` must stay opt-in: the default invocation in `.github/workflows/validate.yml:30` must remain byte-identical, so the guard's CI contract does not change.

A **missing or duplicated** `<!-- SURFACE-BUDGET:START -->` / `<!-- SURFACE-BUDGET:END -->` marker is that malformed path — the file's prose is never scanned as registry data.

10. A declared `allowed-surface:` subtracts **only** when that same file also names the canonical home path (the pointer test).

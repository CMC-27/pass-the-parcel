## What the fix does (operator-authored intent)

A named, low-friction **parcel feedback** route:

1. **A `@parcel-feedback` skill** (or a scoped section in `@sync-architecture` — Phase 3 decides) that, when invoked in a satellite, drafts a parked plan **shaped for this template's backlog** — the existing parked-plan format (`type: backlog`, `claim_status: QUEUED`, Findings with evidence, What-the-fix-does, Open question) — from whatever context the satellite agent has in-session.
2. **Immediate push:** the draft lands where the operator can hand it to the template repo in one action — practically, a drop location (e.g. satellite-local `feedback/` outbox or a templated GitHub issues body via `gh`, per `@report`'s precedent) that the operator copies/commits without re-authoring.
3. **Intake side (template repo):** a short documented intake step — where landed feedback goes (`.devops/backlog/`), who/what triages it, what done-looks-like for "reviewed" — so arriving items never sit unaddressed.

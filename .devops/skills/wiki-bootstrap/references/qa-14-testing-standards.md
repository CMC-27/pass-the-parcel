# Q&A: Testing Standards (Slot 14)

## Why this doc matters

Defines the testing architecture, patterns, and budgets that ensure code quality and prevent regression.

## Required sections

- Test taxonomy table
- Mocking standards
- Performance budgets
- PR checklist

## Questions

1. What test framework(s) are used? (Vitest, Jest, etc.)
2. What is the test location convention? (next-to-source, __tests__/, etc.)
3. What are the per-file performance budgets?
4. Are there integration/E2E test patterns?
5. What is the mock convention and canonical mock location?
6. Is there a pre-merge PR checklist for tests?

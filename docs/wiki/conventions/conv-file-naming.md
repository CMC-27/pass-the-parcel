# File Naming Convention

## Rules

| Type | Pattern | Example |
|---|---|---|
| React components | PascalCase.tsx | `UserProfile.tsx` |
| Utilities | camelCase.ts | `formatCurrency.ts` |
| Hooks | useCamelCase.ts | `useAuth.ts` |
| Context | PascalCaseContext.tsx | `AuthContext.tsx` |
| Types/Interfaces | PascalCase.ts | `UserTypes.ts` |
| Styles | PascalCase.module.css | `Button.module.css` |
| Tests | sourceName.test.ts | `Button.test.tsx` |
| Wiki docs | prefix-kebab-case.md | `ui-button.md` |
